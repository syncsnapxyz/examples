# SyncSnap Next.js App Router Example

This is a simple example of how to use SyncSnap with the Next.js App Router.

## Getting Started

1. Go to [https://syncsnap.xyz/dashboard](https://syncsnap.xyz/dashboard) to get your API key
2. `cp .env.example .env.local` and paste your API key into the newly created `.env` file

3. Run `npm install && npm run dev`

4. Start cross-device uploads!
